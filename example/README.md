# Live2D Example

This example demonstrates how to use the `live2d` package to render and interact with Live2D Cubism models inside a Flutter application.

## Features demonstrated

- Rendering models over a transparent background stacked on top of Flutter gradients.
- Switching between Cubism 4/5 (`.model3.json`) and Cubism 2.1 (`.model.json`) models.
- Controlling motion groups (`Idle`, `TapBody`, etc.) using action buttons.
- Zooming and scaling in real-time via slider.
- Hit area tap feedback via `SnackBar`.

## Running the example

Run the application on an Android, iOS, or macOS device/simulator:

```bash
cd example
flutter run
```
